## 🛠️ Tech Stack & Architecture

### **Core Frontend & Framework**
- **React 19 & TypeScript:** Strongly typed, component-driven UI architecture with modern hooks and state management.
- **TanStack Router:** File-based, type-safe routing providing seamless single-page application navigation and server-side route generation.
- **TanStack Query:** Powerful asynchronous state management and server state synchronization.

### **Styling & UI Components**
- **Tailwind CSS v4:** Utility-first, next-generation styling engine optimized for rapid design and minimal runtime overhead.
- **Radix UI Primitives:** Accessible, unstyled UI components (Dialogs, Dropdowns, Tooltips, Accordions) styled with custom design tokens.
- **Lucide Icons:** Clean, lightweight SVG iconography across all sections.
- **Custom CSS Animations:** Custom marquees, floating keyframes, and smooth micro-interactions.

### **Build Tooling & Optimization**
- **Vite:** Blazing fast development server with Hot Module Replacement (HMR) and optimized Rollup production bundling.
- **Vitest & ESLint:** Integrated testing framework and code quality linting setup.

## 💻 Local Development Setup

To run this portfolio locally on your machine:

### Prerequisites
Make sure you have **Node.js** (v18 or higher) installed on your system.

### 1. Clone the repository
```bash
git clone https://github.com/tariniprasadpati67/portfolio--.git
cd portfolio--
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open **[http://localhost:8080](http://localhost:8080)** in your browser to view the live site.

### 4. Build for production
```bash
npm run build
```
